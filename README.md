⚡ Key Features

- 🛡️ Threat Detection: Identify potentially harmful apps and suspicious activity.
- 🚨 Siren Alert System: Sound an alarm when a configured security threat is detected.
- 📡 Security Radar: View detected applications and security findings.
- 📦 Package Name Detection: Display package names to help identify suspicious applications.
- 🚫 App Blocking: Block supported threats where Android permissions allow.
- 🧹 Uninstall Support: Help users remove identified unwanted or potentially harmful apps.
- 🔍 Security Monitoring: Review detected threats and available app information.
- 💬 Help & Support: Contact the developer through the Help/About section for assistance.

🔐 Our Mission

To make Android security monitoring more accessible by helping users identify suspicious applications, receive alerts, and take appropriate security actions.
